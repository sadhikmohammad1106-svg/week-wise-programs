POSSIBLE CAREER DIRECTIONS

Career Opportunities

These are general career options, not a list of confirmed campus recruiters or placement results.

01

Software Developer

Practise programming, problem-solving, debugging and building useful applications.

02

Web Developer

Build responsive websites using HTML, CSS, JavaScript and suitable backend technologies.

03

Data Analyst

Develop SQL, spreadsheet, Python and data visualisation skills to interpret information.

04

Database Associate

Learn SQL, database concepts, data quality and basic database administration.

05

Software Tester

Understand test cases, bug reporting, software quality and introductory automation testing.

06

Cloud and IT Support

Build knowledge of operating systems, networking, troubleshooting and cloud fundamentals.

Your placement preparation checklist

  • Strengthen one programming language.
  • Practise SQL and basic data structures.
  • Create two or three genuine projects.
  • Upload your work to GitHub.
  • Prepare your resume and practise interviews.
